# 5G-NR-Communication-System
This repository contains MATLAB code for the newcomer summer training at the Communications Technology Laboratory (CTL), National Sun Yat-sen University (NSYSU), supervised by Prof. Chao-Kai Wen. It includes 5G NR SISO/MIMO simulations: OFDM &amp; synchronization; channel/SNR/CFO estimation; LMMSE detection/equalization; LDPC ; and capacity analysis.
